# WaveForge Studio

> Браузерная онлайн-студия для создания и аранжировки музыкальных треков — в духе FL Studio и Ableton Live.

**WaveForge Studio** — это веб-приложение, которое переносит классическую рабочую среду DAW (Digital Audio Workstation) прямо в браузер. Проект предоставляет плейлист-аранжировку с таймлайном, микшер, управление темпом (BPM), drag-and-drop и гибкое управление дорожками — всё это с возможностью сохранять проекты и загружать собственные аудиофайлы на сервер.

## Возможности

### Рабочая область (Workstation)
- **Плейлист (Playlist)** — визуальная аранжировка с таймлайном в долях и секундах, зависящим от текущего BPM.
- **Микшер (Mixer)** — управление дорожками: переименование (двойной клик), регулировка громкости, добавление и удаление треков.
- **Тулбар (Toolbar)** — меню File / Edit / Plugins / Help и контроль темпа **BPM (40–300)**.
- **Drag-and-drop** — перемещение элементов с помощью `react-dnd`.
- **Контекстное меню** — быстрые действия над дорожкой (Rename / Remove Track) по правому клику.

### Проекты и аудио (бэкенд)
- **Регистрация и авторизация** пользователей (сессионная).
- **Управление проектами** — создание проектов и их принадлежность владельцу.
- **Загрузка и хранение аудиофайлов** — треки привязываются к проекту, хранят время начала и длительность.

## Запуск проекта

Проект состоит из двух частей: **бэкенд** (Django API) и **фронтенд** (React + Vite). Для работы необходимо запустить обе.

> Требования: **Python 3.10+** и **Node.js 18+**.

### 1. Бэкенд (Django API)

```bash
cd dp_studio

# Создать и активировать виртуальное окружение (Python)
python -m venv venv
# Windows (PowerShell):   venv\Scripts\Activate.ps1
# Windows (CMD):          venv\Scripts\activate.bat
# macOS / Linux:          source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Применить миграции базы данных
python manage.py migrate

# Запустить сервер разработки
python manage.py runserver
```

API будет доступен по адресу **http://127.0.0.1:8000**.

> **Примечание об окружении.** Если рядом лежит уже созданная папка `venv/`, создайте окружение заново или исправьте путь к интерпретатору в `venv/pyvenv.cfg` — так как в системе может быть установлена другая версия Python.

### 2. Фронтенд (React + Vite)

В отдельном терминале:

```bash
cd frontend

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Интерфейс будет доступен по адресу **http://localhost:5173**.

> Фронтенд обращается к бэкенду по адресу `http://127.0.0.1:8000` (захардкожен в коде). CORS уже настроен на разрешение запросов с `http://localhost:5173`.

### Полезные команды фронтенда

| Команда              | Описание                                   |
|----------------------|--------------------------------------------|
| `npm run dev`        | Запуск dev-сервера Vite                    |
| `npm run build`      | Сборка production-версии                   |
| `npm run lint`       | Проверка кода линтером (ESLint)            |
| `npm run preview`    | Просмотр собранной production-версии       |

## Как это работает (бизнес-логика)

Приложение реализует ключевую модель **«Проект → Треки»**, аналогичную реальным DAW:

### Модель данных

- **Project** — музыкальный проект. Имеет имя, описание, владельца (`owner`) и дату создания. Владелец — авторизованный пользователь, при этом проект **не удаляется**, если владельца больше нет (используется `SET_NULL`).
- **Track** — отдельная дорожка внутри проекта. Хранит имя, аудиофайл, время начала (`start_time`, сек) и длительность (`duration`, сек). При удалении проекта треки автоматически удаляются (каскадная связь `CASCADE`).

### Рабочий процесс

1. **Авторизация** — пользователь регистрируется (пароль хэшируется) и входит в систему. Сессия хранится на клиенте (в `sessionStorage`).
2. **Создание проекта** — владелец создаёт проект; если пользователь не авторизован, `owner` остаётся пустым.
3. **Добавление треков** — на странице проекта загружаются аудиофайлы, которые автоматически привязываются к текущему проекту.
4. **Аранжировка** — в рабочей области плейлиста и микшера пользователь переименовывает, добавляет/удаляет дорожки, регулирует громкость и меняет темп через контроль BPM. Таймлайн пересчитывает доли в зависимости от BPM.

### Ключевые решения

- **Темп → таймлайн:** интервал отображения долей и секунд на таймлайне вычисляется на основе текущего значения BPM, что приближает работу к реальной DAW-навигации.
- **Права владения:** проекты привязаны к пользователям, но отличаются устойчивостью — удаление владельца не разрушает проект (поле может стать `NULL`).
- **Модульность аудио:** `Tone.js` и `Konva` уже подключены и зарезервированы под будущий полноценный аудио-движок и графическую нотацию/секвенсор.

## API

Все эндпоинты доступны через префикс `/api/api/`:

| Метод   | URL                                        | Описание                      |
|---------|--------------------------------------------|-------------------------------|
| GET     | `/api/api/projects/`                       | Список проектов               |
| POST    | `/api/api/projects/`                       | Создать проект                |
| GET     | `/api/api/projects/{id}/tracks/`           | Треки конкретного проекта     |
| POST    | `/api/api/projects/{id}/tracks/`           | Загрузить трек в проект       |
| POST    | `/api/api/register/`                       | Регистрация пользователя      |
| POST    | `/api/api/login/`                          | Вход (имя + пароль)           |
| POST    | `/api/api/logout/`                         | Выход из системы              |

Админ-панель Django доступна по адресу `/admin/`.

## Статус и планы

Проект находится в активной **ранней стадии разработки**. Многие компоненты пока являются заглушками.

**Уже реализовано:**
- Рабочая область с плейлистом, таймлайном и микшером.
- Drag-and-drop и контекстное меню треков.
- Контроль BPM и пересчёт таймлайна.
- Бэкенд с авторизацией и управлением проектами/треками.

**В планах:**
- Подключение полноценного аудио-движка на базе Tone.js (воспроизведение, сэмплы, эффекты).
- Графический секвенсор/визуализация на canvas (Konva).
- Привязка рабочей области к реальным данным проектов из бэкенда.
- Реализация эффектов (Reverb / Delay) и экспорт готового трека.
